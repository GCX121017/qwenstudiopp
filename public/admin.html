1配置 Qwen Studio Token

粘贴 chat.qwen.ai 的登录 Token（JWT）或整段 Cookie。保存前会自动验证连通性，通过后立即生效。若误带引号/说明文字，会自动提取 token 本体。
如何获取 Token？（两种方式任选）
方式 A · JWT Token（推荐，简单）
  1. 浏览器打开 chat.qwen.ai 并确保已登录
  2. 按 F12 打开开发者工具 → 顶部 Console（控制台）
  3. 输入 localStorage.token 回车，复制输出的引号内字符串（eyJ 开头）
⚠ 只复制 token 本体，不要连同中文说明、笔记标注或引号一起复制（工具会自动提取纯净 token；若无法提取会精确指出第几个字符有问题）。 方式 B · 整段 Cookie
  1. F12 → Network（网络） → 刷新页面 → 点任意 chat.qwen.ai 请求
  2. Request Headers 里复制整行 cookie: 的值粘贴进来
注意：token 是你的账号凭证，仅保存在本机配置文件中，请勿泄露给他人。

2本地 API 密钥

调用本地 API 时使用的密钥（Bearer），首次启动自动生成。外部工具里填这个密钥即可。
重新生成后，已保存到 Cherry Studio / zcode 等工具里的旧密钥会立即失效，需要同步更新。
